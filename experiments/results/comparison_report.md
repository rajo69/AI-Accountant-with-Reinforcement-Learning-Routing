# Routing Policy Comparison Report (superseded)

*This page points to the current evaluation sources. The narrative of the
2026-03-26 run that it once held was replaced after the statistical analysis
(Wilson 95% CIs and two-proportion z-tests, commit 441d174) and the
calibration and regime probes (commits 9baba1c, 04f3c2e and the regime-probe
commits that followed) re-tested its claims.*

The authoritative current sources for evaluation results are:

- **Raw numbers** (regenerated by `python -m agent.evaluate [--dataset ...]`):
  - `evaluation_results.json`: raw Claude Haiku confidences
  - `evaluation_results_calibrated.json`: Platt-scaled confidences
  - `evaluation_results_regime.json`: calibrated, with the easy tier reshaped to 0.72
  - `evaluation_results_regime_raw.json`: raw, with the easy tier reshaped to 0.72

- **Statistical summaries** (regenerated by
  `python -m experiments.statistical_analysis [--dataset ...]`):
  - `statistical_summary.md` / `.json`: raw
  - `statistical_summary_calibrated.md` / `.json`: calibrated
  - `statistical_summary_regime.md` / `.json`: calibrated regime probe
  - `statistical_summary_regime_raw.md` / `.json`: raw regime probe

- **Narrative**: the repository [README.md](../../README.md) Results section
  and the 1-page technical note at [paper/one_pager.md](../../paper/one_pager.md).

This page is kept so external references to
`experiments/results/comparison_report.md` resolve to the current sources.
